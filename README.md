# AI TrustHub 善证 TrustAid

医疗求助视频可信度分析与人工审核辅助的本地演示系统。代码与界面沿用原项目名称“善证 TrustAid”，仓库名为 `ai-trusthub`；它不是阿里巴巴官方产品，也不宣称已经与外部平台实现正式接入。

项目用于训练营 AI 与公益场景的工程实践展示。项目由团队合作完成，姚权树参与系统开发与交付；本仓库不将整个项目或团队活动中的口头评价表述为个人独立成果或正式竞赛奖项。开发中使用了 AI 辅助工具。

## 已实现的演示流程

- 在浏览器中解码视频、抽取关键帧并计算画面指纹。
- 将案例、授权状态、分析与审核记录保存在本机 SQLite。
- 从已明确授权公开的演示案例中召回相似内容。
- 将账号关系、项目编号、文本和视频等信号组合为可解释的核对提示。
- 提供人工审核队列与审计时间线；低证据覆盖度不允许自动处置。

系统不开展公开募捐、不经手善款，不作真假、诈骗或违法认定。规则融合分数不是经真实标注集校准的诈骗概率。

## 真实实现与模拟边界

视频指纹、SQLite 持久化与审核流程真实执行。身份验证、第三方账号授权、二维码识别、语音识别和虚拟号码运营商接入仍属于模拟适配器、结构化输入或后续规划。没有生产级访问控制，不可直接作为真实医疗或资金业务上线。

## 本地运行

需要 Node.js 22.13+。安装依赖并从源码构建前端，再启动仅监听本机地址的服务：

```bash
npm ci
npm run build
npm start
```

默认地址：`http://127.0.0.1:4178`。不要直接双击 `offline/index.html`。

首次运行仅生成 4 个以 `DEMO-` 开头的虚构案例；不附带任何历史数据库、病例、身份证、手机号、上传视频或日志。运行后生成的 `local-system/data/` 不应提交 Git。

```bash
npm test
```

测试启动独立的本地服务并使用临时数据目录；不会复用用户已有数据库。公开源码版本不依赖原托管平台的 `.openai` 配置。

## 架构

```text
React 本地页面 -> 视频指纹与结构化输入
              -> Node.js 本地 API -> SQLite / 授权状态
                                  -> 规则融合提示 -> 人工复核 -> 审计记录
```

项目标识图片属于原团队展示资产。依赖许可证适用于各自依赖，不代表项目原创代码自动采用同一许可证。详见 [权利说明](RIGHTS.md) 和 [安全说明](SECURITY.md)。
